# VÉRTICE Design Tokens

Fuente canónica de identidad visual para web y mobile.

## Reglas
- Ninguna pantalla nueva debe definir colores de marca directamente.
- Web y mobile deben consumir estos tokens mediante su adaptador de plataforma.
- Montserrat se usa en títulos y headings; Inter en cuerpo, labels y controles; DM Mono para datos técnicos; Fraunces únicamente en recursos editoriales aprobados.
- La iconografía primaria es Lucide, estilo outlined, trazo 2px y bordes redondeados.
- Azul VÉRTICE (`#0A2A66`) expresa identidad/institución; amarillo ciudadano (`#F5B700`) expresa participación/acción; rojo (`#D72638`) se reserva para alertas críticas y seguridad.
