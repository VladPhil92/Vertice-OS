# VÉRTICE Product System

Este directorio concentra los contratos de coherencia de producto para Web y Mobile: design system, identidad federada CTG One, iconografía, assets, golden screens y criterios de release.

Documentos principales:

- `CROSS_PLATFORM_COHERENCE.md` — invariantes entre Web y Mobile.
- `VISUAL_LANGUAGE_MATRIX.md` — paleta, tipografía y semántica visual canónica.
- `ICONOGRAPHY.md` — gramática iconográfica y reglas de uso.
- `BRAND_ASSET_POLICY.md` — política de logo, wordmark e imágenes.
- `PRODUCT_LANGUAGE.md` — vocabulario y copy del producto.
- `GOLDEN_SCREENS.md` — superficies usadas para validar paridad.
- `PHASE_MOBILE_COHERENCE.md` — fase estructural de convergencia Web/Mobile.
- `PHASE_GOLDEN_SCREEN_CONVERGENCE.md` — migración visual runtime de las superficies móviles primarias.
- `CTG_ONE_MOBILE_AUTH.md` — contrato de federación CTG One con identidad única.
- `RELEASE_CHECKLIST_COHERENCE.md` — evidencia exigida antes de declarar paridad o release.
