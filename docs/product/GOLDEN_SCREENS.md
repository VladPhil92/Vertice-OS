# VÉRTICE Golden Screens

Pantallas obligatorias de validación de coherencia Web/Mobile:

1. Login / identidad
2. Inicio / dashboard ciudadano
3. Territorio
4. Reportes
5. Reputación / perfil
6. Comunidad

## Criterios
Cada par de pantallas debe conservar: marca, color, tipografía, iconografía, vocabulario, jerarquía de CTA, significado de estados, permisos, identidad del usuario y entidades de dominio. La distribución y navegación pueden ser nativas de cada plataforma.
