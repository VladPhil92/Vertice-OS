# VÉRTICE Visual Language Matrix

| Elemento | Web | Mobile | Regla compartida |
|---|---|---|---|
| Fondo | #F7F9FC / superficies blancas | igual | token `background` / `surface` |
| Primario | #0A2A66 | igual | identidad, CTA institucional |
| Ciudadano | #F5B700 | igual | participación, acento |
| Crítico | #D72638 | igual | error/seguridad |
| Display | Montserrat | Montserrat | headings/títulos |
| Body | Inter | Inter | texto, inputs, labels |
| Iconos | lucide-react | Lucide RN adapter | outline, stroke 2 |
| Cards | 18–22 radius | 16–22 radius | misma jerarquía semántica |
| Inputs | border #D6DFEA/#E1E7EF | igual | foco azure |
| CTA CTG One | outline navy + ShieldCheck | igual | federación preferente |
| Assets | `/public/brand` | bundle canónico | mismo arte, no reinterpretación |

La adaptación al dispositivo puede cambiar distribución, densidad, interacción y navegación, pero no identidad, semántica ni jerarquía de acciones.
