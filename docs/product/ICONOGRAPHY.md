# VÉRTICE Iconography

Familia oficial: Lucide.

- Estilo: outline, sin relleno salvo estados excepcionales.
- Stroke: 2 px.
- Esquinas visuales redondeadas.
- Tamaños base: 16, 20, 24, 28.
- Navegación: un solo icono por destino; evitar emoji e iconos decorativos inconsistentes.
- Estados semánticos: `CircleCheck`/`CheckCircle`, `AlertTriangle`, `CircleX`, `Info`, manteniendo el color semántico del design system.
- Acciones: `ArrowRight`, `Plus`, `Search`, `Bell`, `MapPin`, `User`, `ShieldCheck`, `FileText`, `Users`, `Vote`/`Landmark` según dominio.
- Web usa `lucide-react`; mobile debe usar un adaptador Lucide compatible con React Native para conservar nombres y geometría.
