# VÉRTICE Product Language

Vocabulario canónico para web y mobile:

- Inicio
- Territorio
- Reportes
- Acciones comunitarias
- Comunidad
- Reputación
- Perfil ciudadano
- Propuestas
- Gobernanza
- Identidad
- Crowdfunding
- Notificaciones

CTG One se describe siempre como identidad federada, no como una cuenta separada de la app. El CTA canónico es `Continuar con CTG One`. El divisor canónico es `o usa tu cuenta VÉRTICE`.

Los estados de autenticación deben distinguir: credenciales VÉRTICE inválidas, error de federación CTG One, sesión expirada, servicio no disponible y cuenta pendiente de vinculación.
